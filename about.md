# Auto Decorator

Open the **editor pause menu** and press **Auto Deco**.

- Select the part of the layout you want decorated (or select nothing to decorate the whole level)
- Pick a **theme** with the arrows, and/or type a **prompt**
- Press **Generate**

Examples of prompts: `dense purple neon with stars`, `forest with grass and pillars`, `minimal white`, `lava, no floaters, only glow`.

Decoration is made from scaled blocks (no-touch, so gameplay is untouched) using color channels 201-205. **Remove Last** deletes the most recent batch.
